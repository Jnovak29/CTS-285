# M4 Investigation Brief

## Product Slice
US-01 - Monitoring

## Trace to Product Work
Giving a learner completes an activity, when the learner or another user views progress, then the activity is displayed.
Its importance lies in it representing the core value of the monitoring feature.

## Initial Design Question
**Question type:** Dependency / Constraint

Where will learner activity completion data be stored, does a database or storage system need to be ready before this can be implemented?

## Why This Question Matters
developers may use a temporary solution that does not meet requirements, If persistence is later needed, significant changes to data storage and retrieval logic would be needed.

## Planned Evidence
- Dependency map

## Why This Evidence Is a Reasonable Starting Point
A dependency map will help identify which components are involved in tracking learner progress.
